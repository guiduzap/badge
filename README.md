## Comandos Git
- git clone (clonar um repositorio)
- git branch (mostrar a branch atual)
- git checkout -b "Nome da branch" (criar uma nova branch)
- git commit -m "Nome da commit" (salvar alterações)
- git status (verificar status da branch)
- git push origin (enviar alterações ao repositorio remoto)
- git add . (adiciona todos os arquivos do path no stage changes)
- git add arquivo (adiciona um unico arquivo)
